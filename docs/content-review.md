# 콘텐츠 검수 기록 (교사·교과 검수자용)

> **상태: 전체 검수 대기(pending).** 아래 내용은 구현 계획 문서(2026-08-28) §4.1의 고정 문장 fixture를
> 그대로 옮긴 것입니다. 국어 교사 또는 교과 검수자가 승인하기 전까지 앱을 공개 배포하지 않습니다.

## 검수 요청 항목

1. 문장의 맞춤법·문장 부호·초등 3~6학년 어휘 난이도
2. 각 미션의 중심 문장, 승인 순서, 복수 정답 범위가 교과적으로 타당한지
3. 관계 피드백(근거 문구)이 학생 눈높이에 맞는지
4. 오개념 방지 문구(misconceptionGuard)가 실제 오개념을 정확히 막는지

## 미션별 검수 대상

### paragraph-garden-01 — 학교 화단 씨앗 심기 (시간 순서)

- 문장: G1~G5 + GX(관련 없음) — 계획 문서 §4.1 원문 그대로
- 승인 순서: `G1-G2-G3-G4-G5`, `G1-G2-G4-G3-G5`
- sourceNote: 계획 문서 §4.1 고정 문장에서 2026-08-28 작성. 실제 학급 사건·인물 아님.
- misconceptionGuard: 시간 낱말(먼저, 그다음, 마지막으로)을 단서로 삼되 관련 없는 문장(GX)까지 순서에 넣지 않는다.

### paragraph-rain-02 — 젖은 운동장 (원인과 결과)

- 문장: R1~R4 + RX(관련 없음)
- 승인 순서: `R1-R2-R3-R4`
- sourceNote: 계획 문서 §4.1 고정 문장에서 2026-08-28 작성.
- misconceptionGuard: 원인(비가 옴)을 결과(바닥이 젖음)보다 나중에 놓아 인과를 뒤집지 않는다.

### paragraph-library-03 — 두 독서 공간 비교 (비교)

- 문장: L1~L5
- 승인 순서: `L1-L2-L3-L4-L5`, `L1-L4-L5-L2-L3` (밝기 묶음/소리 묶음 순서 교환 가능)
- sourceNote: 계획 문서 §4.1 고정 문장에서 2026-08-28 작성. 실제 도서관 명칭 아님.
- misconceptionGuard: 조용함 비교와 밝기 비교를 섞어 묶지 않고 같은 기준끼리 대응시킨다.

### paragraph-bottle-04 — 잃어버린 물병 찾기 (문제와 해결)

- 문장: B1~B5
- 승인 순서: `B1-B2-B3-B4-B5`
- sourceNote: 계획 문서 §4.1 고정 문장에서 2026-08-28 작성. 실제 학생 사례 아님.
- misconceptionGuard: 문제 확인(B1~B2)보다 해결 결과(B4)를 먼저 단정하지 않는다.

### paragraph-butterfly-05 — 나비 관찰 설명 (설명)

- 문장: F1~F4 + FX(관련 없음)
- 승인 순서: `F1-F2-F3-F4`, `F1-F3-F2-F4`
- sourceNote: 계획 문서 §4.1 고정 문장에서 2026-08-28 작성.
- misconceptionGuard: 날개 특징과 무관한 급식 문장(FX)을 특징 묶음에 넣지 않는다.

### paragraph-playground-06 — 놀이 공간 제안 (주장과 근거)

- 문장: P1~P4
- 승인 순서: `P1-P2-P3-P4`, `P1-P3-P2-P4` (근거 두 문장 순서 교환 가능)
- sourceNote: 계획 문서 §4.1 고정 문장에서 2026-08-28 작성.
- misconceptionGuard: 근거 두 문장의 순서가 바뀌어도 주장(P1)→근거→마무리(P4) 관계가 유지됨을 확인한다.
