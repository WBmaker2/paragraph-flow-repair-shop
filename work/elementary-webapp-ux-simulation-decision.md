# 초등 웹앱 시뮬레이션 필요성 결정

- **결정:** `not-needed`
- **대상:** 문단 흐름 수리소의 6개 문단 수리 미션

## 결정 근거

이 앱은 시간에 따라 움직이는 현상이나 연속적인 수치·물리 모델을 탐색하는 앱이 아닙니다. 학습자는 문장을 읽고, 중심 문장을 선택하고, 문장 순서·관련성·이어 주는 말을 조작한 뒤 근거를 확인합니다.

현재 DOM 조작만으로 다음 학습 루프가 결정적으로 보입니다.

1. 읽기 전에 문단의 흐름을 예측합니다.
2. 선택·순서 이동·보관함 이동으로 한 번에 하나의 문장 관계를 바꿉니다.
3. 근거 피드백으로 결과를 관찰합니다.
4. 오답이면 같은 표면에서 다시 시도하거나 판단을 보류하고 다음 관계로 전이합니다.

따라서 Canvas/WebGL/물리 시뮬레이션, `pause`, `step`, seed/time, 모델 단위·불확실성 설명을 추가하는 것은 현재 학습 목표와 맞지 않습니다. 시뮬레이션 부재를 결함으로 판정하지 않습니다.

## 범위·안전

- 문장·정답·근거는 생성 이미지에 의존하지 않고 DOM 텍스트와 evaluator에 있습니다.
- 기존 `위/아래`, 위치 입력, 보관함, 선택 버튼은 시뮬레이션이 아닌 학습 조작으로 검증합니다.
- `prefers-reduced-motion`은 기존 정적 UI로 학습을 완료할 수 있으므로 별도 시뮬레이션 fallback은 필요하지 않습니다.
- 별도의 시뮬레이션 테스트 문서는 생성하지 않습니다. 구현된 시뮬레이션이 없기 때문에 `elementary-webapp-ux-simulation-test.md`는 N/A입니다.
